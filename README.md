# SENSEMATE – Offline Multimodal AI

### An AI Companion for Visually Impaired People

## About the Project

SENSEMATE is a proposed AI assistant designed to help visually impaired people with everyday activities.

The idea is to use a laptop camera and voice interaction to help users identify objects, read printed text, and understand their surroundings.

## Problem

Simple activities such as finding personal belongings, reading labels, and understanding household devices can be difficult for people with visual impairments.

## Proposed Features

- Find everyday objects
- Read printed text using OCR
- Describe surroundings
- Voice-based interaction
- Spoken AI responses
- Explore offline AI processing

## Technology

- Python
- OpenCV
- Computer Vision
- OCR
- Speech Recognition
- Text-to-Speech
- Qualcomm AI tools

## Project Status

Concept and initial development stage.

The prototype features and performance are yet to be implemented and tested.
